This connector displays a YouTube channel's videos in your timeline.

Enter a YouTube @handle (e.g. @MrBeast) and choose a content type: All content, Videos only, Shorts only, or Live streams only.

Each item shows the video title, full description, thumbnail, and view count. No YouTube API key is required — the connector uses public RSS feeds.

**Note:** An extra request is made on each load to resolve the @handle to a channel ID. If you know the channel ID (starting with UC), you can enter it directly to skip this step.
