Follow an AniList user's public activity in your Tapestry timeline: anime and manga list updates and status posts, with cover art.

Enter the user's name (e.g. `PotatoWithThoughts`, `@PotatoWithThoughts`, or their profile URL). You can optionally limit the feed to list updates only or text posts only.

This connector uses AniList's public GraphQL API and does not require authentication. Only public activity is available.
